# Studio Aura — Landing Page de Arquitetura de Interiores

Landing page autoral para o Studio Aura, escritório de arquitetura e design de interiores de alto padrão em São Paulo.

O projeto foi desenvolvido como uma única página HTML com CSS e JavaScript embutidos, focado em uma experiência sofisticada e envolvente, usando paleta escura, detalhes dourados e tipografia elegante.

## Objetivo

Criar uma landing page que comunique:

- Luxo discreto e requinte
- Sofisticação editorial
- Experiência imersiva de marca
- Clareza na apresentação do processo e do portfólio
- Conversão por meio de contato e links de WhatsApp

## Principais seções

- Hero com vídeo de fundo e navegação premium
- Processo de trabalho em 3 etapas
- Portfólio visual com projetos de interiores
- Seção "Sobre" com posicionamento autoral
- Depoimentos ou prova social
- Formulário de contato e CTA para WhatsApp
- Rodapé com redes sociais e informação de marca

## Tecnologias usadas

- HTML5
- CSS moderno com custom properties, layout responsivo e tipografia escalável
- JavaScript leve para animação de carregamento, barra de progresso e navegação suave
- Fonte Google: `Cormorant Garamond`, `Outfit` e `JetBrains Mono`

## Como visualizar

1. Abra `index.html` diretamente no navegador.
2. Se preferir, hospede em um servidor local simples, por exemplo:

```bash
python -m http.server 8000
```

Em seguida, acesse:

```bash
http://localhost:8000
```

## Notas de estilo

- Paleta escura com superfícies quentes e contraste suave
- Detalhes dourados discretos para reforçar o posicionamento premium
